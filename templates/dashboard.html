Metric glossary and formulas

TP (true positive): actual positive-class images predicted as that class. TN (true negative): all other actual classes correctly predicted as not that class.

FP (false positive): other actual classes predicted as this class. FN (false negative): actual images of this class predicted as another class. TP, TN, FP, and FN are always defined relative to the selected positive class.

For each class, the dashboard uses one-vs-rest (OvR): that class is positive and the other 14 classes are combined as negative. Macro averages give every class equal weight. Overall accuracy is the diagonal total divided by all samples; overall error rate is the off-diagonal total divided by all samples.

Per-class formulas: Precision = TP/(TP+FP); Recall/Sensitivity = TP/(TP+FN); F1 = 2×Precision×Recall/(Precision+Recall); Specificity = TN/(TN+FP); FPR = FP/(FP+TN); FNR = FN/(FN+TP); OvR accuracy = (TP+TN)/(TP+TN+FP+FN); OvR error rate = (FP+FN)/(TP+TN+FP+FN).

If a formula's denominator is zero, its value is defined as 0. Lower error rate is better; higher accuracy, precision, recall, F1-score, and specificity are better.
