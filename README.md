# AgroVision AI — Predictive Analytics

## Project Title
Performance Evaluation and Comparative Analysis of Multiclass Classification Models for Plant Disease Detection

## 1. Introduction
Plant diseases can affect agricultural productivity and crop quality. Machine learning and deep learning techniques can help identify plant diseases by analyzing images of plant leaves.

AgroVision AI — Predictive Analytics focuses on evaluating and comparing machine learning classification models for identifying healthy and diseased plant leaves.

## 2. Objectives
- Study a multiclass plant disease image-classification problem.
- Inspect the dataset and verify its class distribution and labels.
- Evaluate the existing EfficientNetB0 classification model using appropriate performance metrics.
- Compare model performance using consistent experimental conditions, if required.
- Analyze classification errors using confusion matrices and other evaluation results.
- Document the methodology, findings, and limitations.

## 3. Dataset
The project uses the PlantVillage plant leaf image dataset obtained through Kaggle.

The dataset used in the existing AgroVision AI project contains approximately 20,638 valid images across 15 categories involving tomato, potato, and bell pepper plants. The exact dataset version, class distribution, and data splits will be verified during the experimental phase.
