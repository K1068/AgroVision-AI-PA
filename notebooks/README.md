# PA Notebooks

This directory contains the Google Colab notebooks used for the AgroVision AI Predictive Analytics project.

## Notebook

- `AgroVision_PA_Model_Verification.ipynb` — verifies the saved EfficientNetB0 model, prepares the dataset generators, and evaluates multiclass classification performance.

## Reproducibility note

The reported 75.91% accuracy was obtained on a reconstructed validation split. It should not be interpreted as independent test-set performance.
