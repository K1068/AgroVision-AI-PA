# Evaluation Results

This folder contains evaluation outputs for the AgroVision AI Predictive Analytics project.

## Files

- classification_report.csv — per-class precision, recall, and F1-score.
- classification_report.txt — readable classification report.
- confusion_matrix.csv — confusion matrix counts.
- confusion_matrix.png — confusion matrix visualization.

## Evaluation Note

The reported 75.91% accuracy was obtained on a reconstructed validation split of 4,134 images across 15 classes. It has not been established as independent test-set performance.
